我最近一直在想，人類幾年後會怎麼跟軟體互動。現在我們透過 GUI 操作軟體：在電腦上點擊、捲動、打字，在手機上按按鈕、滑來滑去。

但 AI 很可能會讓「意圖驅動的互動」成真。舉個例子，當我想在 Amazon 買東西，我不應該需要打開 Amazon 網站、搜尋商品、看評論、再去 Google 比較一下要買哪個。整個體驗應該是：我直接說「我想買 X，預算 Y，需要 Z 功能，給我推薦三個選項讓我選」。選完之後，AI 自動填好地址、處理付款。

## 拆解這個架構

把這個互動拆成不同層次，就能看清楚實際上發生了什麼。

**Layer 1：人類意圖**
這一層是人說出自己想要什麼。「我想買 X，預算 Y，需要 Z 功能。」我們不告訴系統怎麼做，只說要做什麼。

現在這個協調工作是在我們腦子裡完成的。我們自己決定哪個 app 做什麼事：想搜尋去 Google，想看朋友動態去 Instagram，要聯絡人去 WhatsApp。這導致裝置上的 app 越來越多，因為每個特定情境都有一個專門的 app。未來，AI 應該替我們做這個協調。

**Layer 2：主要 orchestration**
主要 orchestrator 拿到人的意圖之後，要判斷需要跟哪些系統溝通。回到 Amazon 的例子，它要把請求路由到購物平台、評論聚合服務、支付系統、物流服務。它把高層次的意圖（「買這個東西」）翻譯成一個涉及多個專門系統的計畫。

**Layer 3：細部 orchestration**
每個系統都有自己的內部邏輯。Amazon 要搜尋商品目錄、排序結果、確認庫存。評論系統要彙整分數、篩選相關評論。支付處理器要驗證你的卡片、執行交易。這些都是專門負責整體意圖某一塊的執行者。

現在這個細部協調也是用戶自己控制的。如果我去 Booking.com，要自己點很多按鈕選日期、地點、偏好的價格和品質，然後一個個看結果、看評論才能決定。未來，細部 orchestrator 應該只回傳真正符合使用者意圖的結果給上層。

**Layer 4：執行原語**
這一層是實際工作發生的地方：API、資料庫查詢、執行真正操作的函數。Amazon 的搜尋 API、Stripe 的支付 API、地址驗證服務。沒有這一層，什麼都執行不了。上面幾層只是在規劃和路由；這一層才是橡皮真正碰到路面的地方。

每一層都把更高層次的意圖翻譯成更低層次的操作，一路翻到可以真正執行為止。

## Claude Code 就是這個架構的藍圖

把這幾層拆開來看，你會認出一個非常熟悉的東西：Claude Code 加上 sub-agents 和 skills。

在 Claude Code 裡，使用者和主要 orchestrator 對話，說出我們的意圖：想讓這個 codebase 做什麼、計畫是什麼、需要改什麼。

主要 orchestrator 決定怎麼處理這個任務。簡單的請求它直接處理；複雜的探索就呼叫 sub-agents；特定工作流程就叫 skills（YAML 檔會載入 context，讓它知道有哪些 skills 可用）。

Sub-agents 和 skills 就是細部 orchestrators。Explore agent 專門負責理解 codebase；Plan agent 專門負責拆解實作步驟；Skills 則專門處理特定領域的工作流程，像是產生會議記錄或建立新的 skill。每一個都負責整體意圖的某一塊，並想辦法把它執行出來。

最後，它們都使用工具：Read、Edit、Write、Bash、Grep 等等。這些是執行原語，是 filesystem 和 terminal 的 API。它們才是真正在做事的那一層。

對應關係如下：
- **你** - 說出意圖（「把這個重構成 async/await」）
- **主要 orchestrator** - 規劃方法、決定是否需要 sub-agents
- **Sub-agents/skills** - 執行專門的工作流程
- **工具** - 執行實際操作（讀檔、編輯程式碼、跑指令）

這個四層架構，現在已經在運作中了。

## 最終形態

真正有趣的地方在這裡：Claude Code 完全不需要 GUI。你從來沒有點過「重構」按鈕，也沒有打開過「程式碼分析」面板。你說出意圖，它直接透過工具使用來執行。

這就是人類與軟體互動的真正終點。UI 之所以存在，是因為人類需要視覺化的呈現來做決策、應對複雜性。一旦 AI 能可靠地把意圖轉化為執行，UI 這一層就變成了可選的額外開銷，而不是必要的東西。

現在我們還在過渡階段，AI 幫助我們使用 GUI。但最終的形態是：意圖直接到執行，UI 只在你明確想看到過程時才出現。

軟體變成純粹的能力，而不是能力的視覺呈現。你不再跟行動的表示（按鈕、選單、表單）互動，你只是說出你要什麼，能力就執行了。

Claude Code 不只是跟程式碼互動的更好方式。它在示範人類最終將如何跟所有軟體互動的模式。
